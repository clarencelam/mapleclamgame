# mapleclamgame
# This is a simple vanilla javascript browser game. Open/run index.html in a browser to start, then follow the instructions on screen to play. 
# To interact with the food stand or portals, press SPACE. To move, use ARROW UP/LEFT/RIGHT. To throw food, use SPACE.
# The goal of the game is to hit the customers with food to collect coins (mesos) and get upgrades to reach the highest level possible, while avoiding enemies
# Note, this app is under development-- some features may not work as expected.
